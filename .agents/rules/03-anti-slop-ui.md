# Rule: Anti-Slop UI & Weave Design Standards

1. **Sub-Second Doherty Feedback**: Every user interaction (hover, click, drag, upload) must provide instant feedback within 400ms (loaders, skeleton shimmers, optimistic state).
2. **CAD Matrix Discipline**: All drawing canvas interactions must compute screen-to-drawing coordinate translations using standard 2D affine transformation math.
3. **Professional AEC Aesthetic**:
   - Monospace font for numerical quantities, dimensions, coordinates, and CFM airflow.
   - Distinct system colors: Supply (Blue), Return (Green), Exhaust (Amber), Fire Life Safety (Red).
   - High contrast ratios ($\ge 4.5:1$ text contrast, $\ge 3:1$ UI element contrast).
